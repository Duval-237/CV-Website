# CV Website

Site web personnel de type portfolio et curriculum vitæ, conçu pour présenter les informations professionnelles de Duval Nzouekeu de manière moderne, immersive et élégante.

## Description

Ce projet est une page unique (single-page) qui met en avant :
- le profil personnel,
- la formation,
- l’expérience professionnelle,
- les projets réalisés,
- les compétences,
- les langues parlées,
- et les centres d’intérêt.

Le site a été repensé avec un design plus professionnel, visuellement moderne et inspiré d’une expérience cinématographique.

## Technologies utilisées

- HTML
- CSS
- JavaScript
- PHP (pour l’environnement local XAMPP)

## Fonctionnalités

- Navigation fluide entre les sections
- Effets d’apparition au scroll
- Menu responsive
- Styling personnalisé avec un thème sombre
- Background immersif inspiré de l’univers spatial
- Affichage automatique de l’année actuelle dans le footer

## Structure du projet

- `index.html` : page principale du site
- `style.css` : styles et mise en page
- `js/script.js` : interactions et animations
- `img/` : images et icônes du projet

## Objectif

Le but de ce site est de présenter le profil de Duval Nzouekeu de façon claire, professionnelle et visuellement attractive, tout en conservant le contenu du CV original.

## Lancement local

Pour visualiser le site localement, il suffit d’ouvrir le projet avec XAMPP ou un serveur local PHP/Apache.
